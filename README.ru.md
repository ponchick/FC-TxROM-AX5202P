# FC-TxROM-AX5202P

Плата картриджа с маппером MMC3 на базе микросхемы AX5202P.

В теории такой картридж должен поддерживать все типы плат семейства TxROM. На практике проверены только самые распространённые варианты — проблем не выявлено.

## Поддержка PRG RAM и батарейки

Плата позволяет использовать PRG RAM для сохранений. Батарейка CR2032 обеспечивает сохранность данных при выключенной консоли.

- **Если батарейка установлена** (сохранения нужны) — перемычки **NO BATTERY** оставьте разомкнутыми (не запаивайте).
- **Если батарейка не используется** (PRG RAM на плате присутствует, но сохранения не требуются) — запаяйте обе перемычки **NO BATTERY**. В этом случае PRG RAM будет запитываться от основного питания консоли, а данные будут теряться после выключения.

При использовании режима без батарейки следующие компоненты можно не устанавливать:

- Батарея BT1
- Резисторы R1, R2, R3, R4
- Конденсаторы C4, C8
- Диоды D1, D2
- Транзистор Q1

## Выбор CHR ROM / CHR RAM

Некоторые типы игр требуют наличия ОЗУ вместо ПЗУ для знакогенератора. Выбор осуществляется тремя перемычками на плате:

- **Режим CHR ROM** — замкните верхнюю пару контактов.
- **Режим CHR RAM** — замкните нижнюю пару контактов.

## Настройка Mirror Control (поддержка mapper 118)

Две перемычки **MIRROR CONTROL** управляют коммутацией сигналов `CHR A17` и `CIRAM A10`. Это необходимо для корректной работы разных подтипов плат TxROM.

- **Верхнее положение** — для mapper 118 (платы **TKSROM** и **TLSROM**).
- **Нижнее положение** — для стандартных TxROM (например, **TKROM**, **TLROM**) и большинства других игр на MMC3.

Если вы не используете mapper 118, держите перемычки в нижнем положении.

## Выбор типа ПЗУ (распиновка)

Две перемычки переключают выводы 1 и 31 микросхемы ПЗУ, так как у разных типов памяти назначение этих ножек отличается.

- **Верхнее положение** (`EEPROM/FLASH`) — для электрически стираемых ПЗУ (EEPROM) и FLASH-памяти.
- **Нижнее положение** (`UV EPROM`) — для стираемых ультрафиолетом ПЗУ (UV EPROM).

Установите перемычки в соответствии с типом используемой микросхемы.
